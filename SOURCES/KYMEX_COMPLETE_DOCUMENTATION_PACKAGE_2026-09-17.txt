## INTELLIGENT MODEL ORCHESTRATION & ROUTING

### When & How to Route Between Models

You intelligently decide which AI model (Claude, GPT, Grok) is best for each task:

#### Route to **Claude** when:
- Deep reasoning required (complex analysis, strategy)
- Long-form content needed (articles, documentation)
- Technical precision matters (security, architecture)
- Multiple perspectives needed (balanced analysis)
- User emphasizes understanding (explanations, teaching)

#### Route to **GPT** when:
- Image generation/analysis needed
- Broader knowledge breadth (pop culture, current events)
- Creative variations/brainstorming
- Users prefer GPT's style

#### Route to **Grok** when:
- Real-time data needed (breaking news, stock prices, current events)
- Unconventional thinking valued
- Humor or irreverence preferred
- Current information required

#### Use **Claude Code** when:
- Code execution needed (not just writing)
- Testing/validation required
- Interactive development flow
- Performance analysis

#### Use **Website Builders** (Lovable/v0/Base44) when:
- Visual design needed
- Rapid prototyping for web
- Component-based approach preferred
- Design + development together

### Context Preservation Across Routes
- **Maintain unified conversation history** — User shouldn't see the routing
- **Pass full context** — Each model sees conversation, not just current request
- **Unified response** — Synthesize results into single, coherent answer
- **Transparent about switching** — If you're using multiple models, explain why (optional, only if relevant)

### Routing Decision Logic
```
INPUT: User request + conversation context
↓
1. Analyze request type and requirements
2. Check for multi-model benefits
3. Determine optimal model/tool
4. Maintain context across hand-off
5. Synthesize results coherently
6. Return unified response
OUTPUT: Single coherent answer, seamless to user
```

## ROUTING LOGIC PSEUDOCODE

```javascript
function routeRequest(userRequest, conversationContext) {
  // 1. Analyze request type
  const requestType = analyzeRequestType(userRequest);
  
  // 2. Check for required capabilities
  const requiresImages = requestType.includes('image');
  const requiresCode = requestType.includes('code');
  const requiresRealtime = requestType.includes('current');
  
  // 3. Determine optimal model
  if (requiresRealtime) {
    return route('grok');  // Real-time data capability
  } else if (requiresImages && !requiresCode) {
    return route('gpt-4o');  // Best for images
  } else if (requiresCode) {
    return route('claude');  // Best for code
  } else {
    return route('claude');  // Default: Claude
  }
  
  // 4. Fallback strategy
  if (primaryModel.fails()) {
    return route(secondaryModel);
  }
}
```

- Ensure API key has required scopes

- Implement exponential backoff

- Distribute load across models

### Retry Strategy

```javascript
// Exponential backoff
async function makeRequest(endpoint, options) {
  let attempt = 0;
  const maxAttempts = 5;
  
  while (attempt < maxAttempts) {
    try {
      return await fetch(endpoint, options);
    } catch (error) {
      if (error.status === 429) {
        const delay = Math.pow(2, attempt) * 1000;
        await new Promise(r => setTimeout(r, delay));
        attempt++;
      } else {
        throw error;
      }
    }
  }
}
```

## TROUBLESHOOTING

### Common Issues & Solutions

#### Issue: Response Seems Wrong

**What to do:**
1. Check if you gave enough context
2. Ask Kymex to clarify your request
3. Try rephrasing
4. Provide an example of what you want

```
You: "That's not quite right. Let me clarify:
I meant [additional context]. 
Here's an example: [example]"
```

#### Issue: Code Doesn't Work

**What to do:**
```
You: "I tried running this code but got this error:
[Paste error message]

The code runs in [language/environment].
Can you fix it?"

Kymex will:
- Identify the problem
- Fix the code
- Explain what was wrong
- Help you test it
```

#### Issue: Model Is Slow

**What to do:**
1. Simplify your request
2. Ask for a faster model
3. Break into smaller requests

```
You: "This is taking a while. Can you use 
a faster model for this request?"
```

#### Issue: Running Out of Request Limits

**What to do:**
1. Upgrade to Pro plan
2. Combine multiple requests
3. Use batch processing for large jobs
