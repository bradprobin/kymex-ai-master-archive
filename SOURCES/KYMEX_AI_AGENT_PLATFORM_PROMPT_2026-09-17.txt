AI AGENT PLATFORM — COMPLETE WEBSITE BUILD PROMPT

Build a production-ready AI Agent platform with a premium, modern iOS-inspired UI, optimised primarily for mobile and responsive across tablet and desktop.

Do not copy ChatGPT, Claude, Cursor, Apple, or any other product pixel-for-pixel. Create an original interface using the same broad design principles: clean hierarchy, rounded surfaces, system-style typography, subtle shadows, bottom sheets, floating controls, translucent/glass surfaces, smooth native-feeling animations, excellent spacing, and responsive layouts.

The application should feel like a serious native AI application translated to web rather than a collection of mock screens.

CORE PRODUCT PURPOSE

Build an AI Assistant / AI Agent platform that can function as a highly capable general-purpose assistant and development workspace. Depending on the task, refer to the AI as an Agent, Assistant, Coding Agent, Research Agent, Creative Agent, etc.

The platform must support:
- Conversational AI
- Reasoning and problem solving
- Writing and rewriting
- Research
- Coding and debugging
- HTML, CSS, JavaScript and other programming languages
- Website and application development assistance
- Prompt creation and optimisation
- Prompt-file generation
- Source-code generation
- File analysis
- Image understanding
- Image generation
- Image editing
- Video generation
- Projects and persistent workspaces
- Agent building
- Model selection
- Voice interaction
- Public-link analysis
- External platform integrations
- AI provider configuration
- Tool and MCP-style integrations
- Usage and credit management
- Subscription management
- Administration and moderation

The system must use real application state and real backend enforcement wherever a capability is enabled. Never represent an operation as completed when it has not actually completed.

COLOR SCHEME & BRANDING

The application MUST use a strictly limited color palette:
- PRIMARY: Blue (#0066FF or similar professional blue)
- SECONDARY: Green (#00CC66 or similar vibrant green)
- NEUTRAL: Grays for backgrounds, borders, text (no other colors)

Apply this color scheme to:
- All buttons and CTAs (Blue primary, Green for success/confirmations)
- Links and interactive elements
- Status indicators (Blue for info, Green for success, Grays for neutral/disabled)
- Accent elements and highlights
- Charts and data visualization
- Card borders and focus states

Remove all unnecessary colors. The interface should feel clean, focused, and professional using only these three color families.

SIDEBAR NAVIGATION — ChatGPT-STYLE IMPLEMENTATION

The application MUST hide all secondary pages in a collapsible sidebar at the TOP LEFT (mobile) or LEFT EDGE (desktop/tablet).

Mobile Layout:
- Top-left hamburger menu icon
- Tapping reveals full-height sidebar overlay from left edge
- Sidebar contains navigation hierarchy (see structure below)
- Sidebar can be dismissed by tapping background or X icon
- Main chat area remains visible and editable while sidebar is open (semi-transparent overlay)

Desktop/Tablet Layout:
- Persistent or collapsible left sidebar (300px default, collapsible to icon-only)
- Shows navigation tree on desktop
- Smooth collapse/expand animation
- Preserve sidebar state in localStorage

Sidebar Navigation Structure:

PRIMARY ACTIONS (Top):
- New Chat (prominent button, Blue, full-width)
- Model Selector (if multiple models available)

MAIN SECTIONS:
- Home
- Chats/Conversation History (collapsible list)
- Create (submenu: Image Gen, Video Gen, Coding)
- Projects
- Library

SECONDARY/SETTINGS (Bottom):
- Integrations
- Agent Instructions
- Settings
- Notifications
- Help & Support
- Profile (with logout)

PAGES NOT IN MAIN NAV (accessible via settings/profile/contextual menus):
- Account settings
- Subscription/Billing
- Usage/Credits
- Security
- Data management
- API configuration (admin only)
- Feature flags (admin only)

The main content area should now show a broad, spacious chat interface (similar to ChatGPT) rather than cramped vertical layouts. Chat messages should have generous padding and breathing room.

import { ChevronDown, Plus, Menu, X } from 'lucide-react';

  const [expandedSections, setExpandedSections] = useState({
    chats: true,
    create: false,
  });

    setExpandedSections(prev => ({
      ...prev,
      [section]: !prev[section]
    }));
  };

  const handleNavigate = (page) => {
    onNavigate(page);
    onClose(); // Close sidebar on mobile after navigation
  };

  const SidebarContent = () => (

```jsx
import React, { useState, useRef, useEffect } from 'react';
import { Send, Plus, Paperclip } from 'lucide-react';
import './ChatSpace.css';

const ChatSpace = ({ messages, onSendMessage, isLoading }) => {
  const [input, setInput] = useState('');
  const messagesEndRef = useRef(null);

  useEffect(() => {
    messagesEndRef.current?.scrollIntoView({ behavior: 'smooth' });
  }, [messages]);

  const handleSend = () => {
    if (input.trim()) {
      onSendMessage(input);
      setInput('');
    }
  };

  const handleKeyPress = (e) => {
    if (e.key === 'Enter' && !e.shiftKey) {
      e.preventDefault();
      handleSend();
    }
  };

  return (
    <div className="chat-space-container">
      {/* Messages Area */}
      <div className="chat-messages-area">
        {messages.length === 0 ? (
          <div className="chat-empty-state">
            <h1>Start a new conversation</h1>
            <p>Ask me anything. I'm here to help.</p>
          </div>
        ) : (
          messages.map((msg, idx) => (
            <div 
              key={idx} 
              className={`chat-message ${msg.role}`}
            >
              <div className="message-content">
                {msg.content}
              </div>
            </div>
          ))
        )}
        {isLoading && (
          <div className="chat-message assistant loading">
            <div className="message-content">
              <div className="typing-indicator">
                <span></span><span></span><span></span>
              </div>
            </div>
          </div>
        )}
        <div ref={messagesEndRef} />
      </div>

      {/* Input Area */}
      <div className="chat-input-area">
        <div className="chat-input-container">
          <button className="chat-action-button attach-button">
            <Paperclip size={20} />
          </button>
          
          <textarea
            className="chat-input"
            value={input}
            onChange={(e) => setInput(e.target.value)}
            onKeyPress={handleKeyPress}
            placeholder="Type your message here..."
            rows="1"
          />

          <button 
            className="chat-action-button send-button"
            onClick={handleSend}
            disabled={!input.trim() || isLoading}
          >
            <Send size={20} />
          </button>
        </div>
        <p className="chat-disclaimer">AI can make mistakes. Always verify important information.</p>
      </div>
    </div>
  );
};

export default ChatSpace;
```
